# Tayrona Catering — AI Engineering & Design Rules

## Project
Real production website for Tayrona Catering, Toronto/GTA. The site must communicate premium catering, gastronomy, trust, warmth, strong photography and professionalism.

## Non-negotiable
A functional MVP is NOT permission for low-quality design. Reduce scope when necessary; never reduce visual quality, UX, accessibility or maintainability.

Never create a generic SaaS dashboard, CRUD application, university-project aesthetic, AI-template aesthetic, random card collection, or low-fidelity prototype.

## References
- The Graze Anatomy: https://thegrazeanatomy.com/
- Current Tayrona: https://tayronacatering.ca/

The Graze Anatomy is the principal visual/UX reference. Tayrona's current site is the source for existing content, brand clues and assets where applicable. Do not copy source code or assume its technology.

## Assets
Audit and reuse existing Tayrona photography before using placeholders. Image choice must follow content → purpose → image → component. Never invent photos, testimonials, products, prices, reviews, legal claims or business facts.

## Architecture
Use Next.js, React, TypeScript, App Router and Tailwind CSS. Prefer reusable components and structured content over hardcoded JSX. The architecture must be ready to evolve toward products, cart, checkout, Square, delivery, pickup, quotes, catering, Food Truck, festivals, specials, events and content administration.

Do not silently select a database, CMS, payment architecture or backend.

## UI
Tailwind is the base. External libraries such as Preline, Magic UI or Ant Design may be used only when they add real value and can be visually integrated. Do not mix libraries indiscriminately.

## Quality
Before completion verify desktop, tablet, mobile, hierarchy, typography, spacing, imagery, accessibility, SEO basics, keyboard/focus states, console errors, TypeScript, lint and production build.

## Workflow
inspect → understand → plan → implement → validate → visual review → build → deploy when requested.

## Current priority
Publish the first real high-quality Tayrona website version today. Scope can be reduced; quality cannot.
