# Tayrona Visual Audit

Before major visual implementation, inspect:
1. current Tayrona website/content;
2. project assets;
3. The Graze Anatomy;
4. repository structure.

Analyze the reference for information hierarchy, navigation, product presentation, photography, editorial composition, CTA placement, category discovery, product detail depth and content density.

Audit Tayrona for branding, existing photography, services, products, categories, messaging and business information.

Separate confirmed information from inference and missing information.

Classify images by subject, orientation, quality, likely section, crop and priority. Suggested categories: hero, charcuterie, catering, events, food-truck, desserts, festivals, general, team, decorative.

Never invent business facts. If an asset is missing, document it rather than silently replacing it with invented content.
