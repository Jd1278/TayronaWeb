# Tayrona UI

Create a premium catering experience inspired by The Graze Anatomy but adapted to Tayrona.

Favor large photography, editorial composition, generous whitespace, intentional typography, clear CTAs, elegant interactions and strong mobile composition.

Avoid dashboard aesthetics, excessive rounded cards, arbitrary shadows/gradients, dense grids, repetitive card walls, visual noise and generic AI-template layouts.

Use reusable components such as Header, Footer, Hero, SectionHeader, ProductCard, ProductGrid, ServiceFeature, ImageFeature, CTASection, FestivalFeature and FAQ.

Tailwind is primary. Use component libraries only when they solve a real need and fit the visual system.

Test desktop, tablet and mobile. Use semantic HTML, meaningful alt text, visible focus states, keyboard navigation and accessible controls.
