# Tayrona Quality

Do not treat "it compiles" as "it is finished".

Visual QA:
- premium quality
- strong composition
- coherent typography
- consistent spacing
- intentional image crops
- no broken images
- no accidental placeholders
- no excessive cards
- coherent UI patterns
- clear primary CTA
- clear navigation

UX QA:
- understandable navigation
- valid links
- meaningful buttons
- usable forms
- working mobile navigation
- discoverable important content
- no dead-end interactions

Responsive QA:
- desktop
- tablet
- mobile
- no overflow
- no clipped text
- no broken grids
- usable touch targets

Accessibility:
- semantic structure
- heading hierarchy
- alt text
- keyboard navigation
- focus states
- contrast
- labels

Engineering:
- lint
- typecheck
- build
- console errors
- duplicated logic
- hardcoded business content
- broken imports
- obvious performance issues

Final question: Would a real catering business confidently publish this page as its public website? If not, continue improving.

Scope reduction is acceptable. Quality reduction is not.
